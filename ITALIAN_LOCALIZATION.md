# Italian localization snapshot

Published snapshot: 23 October 2026.

This fork publishes the reviewed SOURCE42 Italian localization of Frappe, including source fixes needed for complete messages, extraction and contextual display. The `italian-localization` branch is a pinned snapshot based on upstream [`faea3728fcd1`](https://github.com/frappe/frappe/commit/faea3728fcd14b7d3f1a2d9f5b3259bf3ef94734); it is not a claim to match today's upstream `develop`.

Use the matching branches of both forks:

- [Frappe](https://github.com/arminiogroup/frappe/tree/italian-localization)
- [ERPNext](https://github.com/arminiogroup/erpnext/tree/italian-localization)

This app's catalogue has **8,696 reviewed entries**: 3,155 translations added or filled, 2,669 existing translations corrected and 2,872 retained after review. Together the two catalogues contain **20,949 reviewed entries**, with no current blanks or fuzzy entries. Counts compare against the original pinned Italian POs; an added entry does not necessarily mean a new English source string. The published POT and Italian PO accompany the source snapshot.

Catalogue review is complete for this snapshot. Broader standard-module, ordinary-user, visual, responsive and native PDF/printing acceptance remains open. Known UI limits include English accessibility filter prefixes and clipped compact report headers. Reconciliation with newer upstream development also remains separate.

These are independently maintained forks. Upstream source fixes and translation submissions are a separate contribution process; publication here does not imply upstream acceptance. `develop` is reserved for upstream tracking.

For upstream synchronization, translation-conflict handling and deployment checks, see the [update guide](UPDATING_ITALIAN_LOCALIZATION.md).
